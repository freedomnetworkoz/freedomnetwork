Freedom Node lets people browse and host Freedom websites, communicate with saved contacts, use Freedom Mail and participate directly in the peer-to-peer network. It includes the `freedom://` browser, encrypted TCP and QUIC connections, LAN and Internet peer discovery, relay support, multiple hosted sites, media streaming and a bundled PHP environment.

The release is portable as an application folder on the same Windows computer. Every new computer should start with a fresh Node installation and generate its own PeerID—do not clone one active identity across multiple machines.

This is preview software, not an anonymity claim. Direct peers may see IP addresses, relay operators can observe connection metadata and public-network resilience is still being expanded. The project welcomes careful testing and responsible security reports that do not expose private user data.

Download the Windows x64 ZIP from the GitHub Releases page, verify the published SHA-256 checksum, extract the complete folder and run `Freedom.exe`

Freedom Node is open-source software under `AGPL-3.0-only`. Modified network-facing versions must make their corresponding source available under the licence. Official branding and Authority signing material remain separate.
